# DMM 試作 A(ブレッドボード、Arduino Mega)

目的: 手元の Arduino Mega で ADS124S08 を読み、PC と OLED に出す。ファームの骨格を作る。精度は 4½ 桁ほどでよい。

- 回路図: `stageA.schjson`(`stageA.ccad` から作る: `ccad dmm/stageA.ccad`。ERC エラー 0)
- J3 は Mega へのジャンパ線の束(Mega そのものは描いていない)
- Pico 版は `stageA_pico.ccad`(B か C の段で使うかもしれないので残す)
- 部品(ユーザーのライブラリに追加): `ADS124S08_TQFP`(ピン番号は VQFN 版と同じ。ランドは概算)、`RPi_Pico`

## 構成

```
PC ─USB─ Arduino Mega ─SPI(5 V)─ ADS124S08(変換基板)
                      └─I2C────── OLED(SSD1306)
```

- **IOVDD を 5 V にして、Mega の 5 V の信号を直接つなぐ**(データシート: IOVDD は DVDD〜5.25 V、DVDD は 2.7〜3.6 V)。レベル変換は要らない。
- DVDD は Mega の 3.3 V ピン、AVDD は Mega の 5 V を R1(10 Ω)+ C1(10 µF)+ C2(100 nF)で濾したもの。USB の 5 V はノイズが多いので、A の段ではこれで様子を見る。
- GND は1本(AVSS = DGND = Mega の GND)。B の段でアナログとデジタルを分ける。
- 基準は内蔵の 2.5 V(REFOUT に C5 1 µF)。
- **USB は絶縁していない。** A の段では、基板の上の電圧(REFOUT を分けたもの)と、HM310 のように出力が浮いている機器だけを測る。PC と GND がつながった機器を測るのは、絶縁してから。

| SCLK | 11 | D52 | SCK |

- **OLED モジュールはピンの並びが製品で違う**(VCC と GND が逆のものがある)。挿す前に基板の印字を見る。
- 5 V で使えるモジュール(3.3 V のレギュレータが載っているもの)か確かめる。多くの 0.96 インチのものは 3.3〜5 V 対応。

### 2つ目の基準 ADR4525(U2)

| ADR4525 | ピン | つなぐ先 |
|---|---|---|
| VIN | 2 | 5V(C6 100 nF + C7 1 µF) |
| GND | 4 | GND |
| VOUT | 6 | ADS124S08 の AIN4(3 番ピン)と REFP0(30)、C8 1 µF(データシート: 出力に 1 µF 以上が必要) |
| NC | 1・3・5・7 | 内部で未接続 |
| TP | 8 | **どこにもつながない**(テスト用) |

- ADS124S08 の REFOUT は AIN5(2 番ピン)にもつなぐ。REFN0(29)は GND。
- 2つの基準の比べ方:
  1. **差を直接測る**: AIN4 − AIN5 を PGA の利得 128(満量程 ±19.5 mV)で測ると、2つの基準の差(数 mV 以下)がそのまま出る。差が小さいので、物差し(内蔵の基準)の誤差はほとんど効かない。
  2. **物差しを入れ替える**: ADC の基準を REFP0(ADR4525)に切り替えて、J2 の入力を測り直す。同じ電圧が両方の物差しでどう読めるかを比べる(2.5 V ちょうどは満量程を超えるので、分圧した電圧で比べる)。B の段で外部の基準に切り替える練習にもなる。
- データシートの保証: 内蔵 ±0.05%(1.25 mV)、ADR4525 B グレード ±0.02%(0.5 mV)。差が 1.75 mV 以内なら両方とも保証の範囲。ただし ADR4525 は**はんだ付けで ±0.02% ずれうる**(SOLDER HEAT SHIFT)。

J2(試験用の入力): REFOUT・AIN0・AIN1・AIN2・AIN3・GND。REFOUT を抵抗で分けて AIN に入れれば、外部の電源なしで試せる。

AINCOM(1 番ピン)は GND につなぐ。J2 の入力を GND を基準に測れる(`v 0 com`)。
使わない ADC の入力(AIN6〜11・REFP1/REFN1)は開放(データシート 10.1.5: 漏れ電流が一番小さい)。

## はんだ付け

- ADC は変換基板にピンヘッダを付けて「ADC モジュール」にし、ブレッドボードに挿す。**B の段ではこのモジュールをユニバーサル基板のソケットに挿して使い回す**(ADC は 1 個 3,000 円ほどするので)。AVDD・IOVDD・DVDD のパスコンと REFOUT のコンデンサ(C2〜C5)は、モジュールの上に載せておくと B でもそのまま使える。

- TQFP の 0.5 mm ピッチは、フラックスを塗って全部のピンにはんだを流し、ブリッジをはんだ吸い取り線で取る方法が楽。
- 付けたら、隣のピンとのショートをテスターで全部確かめる(特に電源と GND)。
- コンデンサ(C2〜C5)は ADC のピンの近くに。長いジャンパ線の先に付けると効かない。

## ファームの最初の手順(Arduino)

スケッチは `firmware/dmm_stageA/`(使い方は `firmware/README.md`)。下の手順はそのコマンドで、`id` → `mon` → `v 0 com` → `refdiff` → `noise 100` の順に進める。

1. SPI はモード 1: `SPISettings(1000000, MSBFIRST, SPI_MODE1)`。SCLK の上限は周期 100 ns(10 MHz)。
2. D53 は SPI を使うとき必ず出力にする(Mega の決まり。CS に使うのでちょうどよい)。
3. RESET(D5)を High にして、少し待つ。
4. ID レジスタ(00h)を読む(RREG コマンド)。下位 3 bit が `000` なら ADS124S08。**ここで読めれば配線はおおむね正しい。**
5. 内部の電源の監視(SYS レジスタの SYS_MON)で AVDD を測る。5 V 付近が出るか。
6. 内蔵の基準を有効にし、AIN0-AIN1 の差動を測る。J2 で REFOUT を 2 本の抵抗で分けて入れ、計算どおりの比になるか。
7. 2つの基準の差: AIN4 − AIN5 を利得 128 で測る。1.75 mV 以内か。温め・冷ましで差がどう動くかも記録する。
8. 入力を短絡して 100 回測り、ばらつき(標準偏差)を記録 → `../log.md` に書く。
9. PC への送信(シリアル)、OLED の表示。

## 道具の使い方

- OWON HDS2202S: SPI の波形(SCLK と MISO)と、AVDD のノイズを見る。電池で動かすと GND のループを作らない。2 ch の GND は共通なので、違う電位に当てない。
- HM310: REFOUT の分圧の次に、0〜2.5 V 程度を入れて直線性を見る(分圧してから入れる。AIN の範囲を超えないこと)。

## A の段で分かったら B に持っていくこと

- ノイズの大きさ(USB の 5 V から AVDD に入るノイズが効いているか: AVDD を電池に替えて比べる)
- ファームの骨格(レンジの設定・自己校正の手順)
- B でもマイコンを Mega のままにするか、Pico に替えるか
