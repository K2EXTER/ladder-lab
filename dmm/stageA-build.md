# DMM 試作 A を組む手順(チェックリスト)

設計と配線の表は `stageA.md`、ファームのコマンドは `firmware/README.md`。ここは**組む日にこの順で進めるための手順**。各段に「合格」を書いた。合格しないまま次へ進まない(壊すと ADC は 1 個 3,000 円)。

結果は段ごとに `../log.md` に 1 行ずつ書く(記事の素材になる)。

---

## 0. 届いた部品を確かめる

- [ ] ADS124S08IPBS ×2(TQFP-32。1 個は予備にして、まず 1 個だけ使う)
- [ ] 秋月 AE-QFP32-5X5-0.5(QFP32 0.5 mm → DIP32)
- [ ] ADR4525WBRZ-R7(SOIC-8)と SOP8 の変換基板
- [ ] 0805 の 100 nF・1 µF、リード付きの 100 nF・1 µF・10 µF
- [ ] 抵抗 10 Ω ×1(AVDD のフィルタ)、10 kΩ 1% ×2(REFOUT の分圧)
- [ ] ピンヘッダ、ブレッドボード、ジャンパ線
- [ ] フラックス、はんだ吸い取り線、ルーペ、先の細いピンセット
- [ ] OLED は**あとで**(最初はファームの `USE_OLED` を 0 にして、OLED なしで進める)

## 1. ADC を変換基板に付ける

1. **向きを決める**: ADS124S08 の 1 番ピンの印(本体の角の丸いくぼみ)と、変換基板の 1 番の印を合わせる。
2. **変換基板の番号を確かめる**: 基板の印字で、QFP の 1 番のパッドが DIP の何番に出ているかを見る。**AE-QFP32-5X5-0.5 は「DIP の番号 = QFP の番号」だった(2026-11-15 に確かめた)**ので、下の表をそのまま使う。
3. フラックスを塗り、角の 1 本を仮止め → 位置を直す → 対角を止める → 全部のピンにはんだを流し、ブリッジを吸い取り線で取る。
4. ピンヘッダを付ける(ブレッドボードに挿す向き)。

**合格**(テスターの導通):
- [x] 隣り合うピンがどこもつながっていない(特に **14-15・15-16(DGND・IOVDD・DVDD)、26-27-28(AVDD・AVSS・AVSS-SW)、23-24(REFOUT・REFCOM)**)
- [x] IC の足の根元と、ピンヘッダの同じ番号がつながっている(全部。ルーペで足の浮きも見る)

## 2. パスコンを付ける(ADC のピンのできるだけ近く)

| コンデンサ | 間 | メモ |
|---|---|---|
| C2 100 nF(0805) | 26 AVDD − 27 AVSS | ピンヘッダの 2 本の間に直接(はんだの盛られた側。IC までの配線は約 1 cm で十分近い) |
| C3 100 nF(0805) | 15 IOVDD − 14 DGND | 同上 |
| C4 100 nF(0805) | 16 DVDD − GND | DGND(14)か、GND にした CLK(17)へ |
| C5 1 µF(0805) | 23 REFOUT − 24 REFCOM | 内蔵の基準に必須 |
| C1 10 µF(リード付き) | AVDD − GND | ブレッドボードの R1 のすぐ後 |

**合格**: [x] 付けたあと、もう一度 14-15・26-27・23-24 がショートしていない(コンデンサ越しなので、テスターの抵抗が最初小さく、だんだん上がっていくのは正常)

## 3. ADR4525 を SOP8 の変換基板に付ける

- 1 番ピンの印を合わせる。使うのは 2 VIN・4 GND・6 VOUT だけ。**8 TP はどこにもつながない**。
- C6 100 nF + C7 1 µF を VIN−GND、**C8 1 µF を VOUT−GND**(データシート: 出力に 1 µF 以上が必須)。
- **はんだ付けの熱で ±0.02% ずれうる**(データシートの SOLDER HEAT SHIFT)。付けた日を log.md に書き、`refdiff` を何日か続けて取ると、落ち着いていく様子が記事になる。

- SOP8 の変換基板では 2・4・6 番が隣どうしでないので、C6・C7・C8 は**リード付きをブレッドボードでモジュールのすぐ横に挿す**(足を短く。1〜2 cm 離れても C8 の「出力に 1 µF 以上」は効く)。近くに付けたいときは、中で未接続の 3 番を 4 番(GND)とつないで 2-3 に、5 番を 4 番とつないで 5-6 に 0805 を渡す手もある(**8 番 TP は使わない**)。

**合格**: [x] 2-4 番の間がショートしていない [x] 6-4 番の間がショートしていない(2026-11-15 にはんだ付け)

## 4. ブレッドボードで配線する

配線は上の表と `stageA.md`。加えて:

- J2 に REFOUT の分圧: REFOUT −(10 kΩ)− AIN0 −(10 kΩ)− GND。AIN0 は 1.25 V になるはず。
- 電源の線は短く。ジャンパ線の束は ADC の入力(AIN)から離す。

**合格**(**通電の前**に、USB を挿さずにテスターで):
- [x] Mega の 5 V − GND、3.3 V − GND、AVDD(R1 の後)− GND がショートしていない(0 Ω 近くなら配線を見直す)
- [ ] 表と配線を 1 本ずつ見比べて、線に印を付けた(特に DIN と DOUT の取り違え、CS と START の取り違え)

## 5. 初めての通電(電流を見ながら)

1. **Mega だけ**: ADC モジュールを抜いた状態で USB を挿し、ファーム(`USE_OLED 0`)を書き込む。シリアルモニタ(115200 baud、改行 LF)が開けるか。`id` は当然失敗する(線がつながっていない)のでよい。
2. USB を抜き、ADC モジュールと ADR4525 を挿す。
3. **電流を制限して入れる**: HM310 を 9 V・電流制限 200 mA にして、Mega の DC ジャック(か VIN と GND)に入れる。USB はまだ挿さない。
   - 「Mega だけ」の電流は、**Mega から全部の線を抜いて**測る。**電源の線(5V・3.3V・GND)だけ抜いて信号の線を挿したままにしない**: ファームが動いていると High の信号ピンから ADC の保護ダイオードを通って Low のピンへ流れ(逆給電)、2026-11-15 には「Mega だけ」の方が 70 mA も多く見えた。ADC と Mega のピンにも悪い
   - [ ] 電流が Mega だけのとき(先に測っておく)と比べて、大きく増えていない(ADC と ADR4525 の分は数 mA 以下のはず。数十 mA 増えたらすぐ切って、ショートを探す)
   - [ ] 10 秒ほど待って、ADC・ADR4525・R1 を指で触れて熱くない
   - **制限にかかったら**(2026-11-15 に実際にあった): 出力を切り、Mega から線を全部抜いて Mega だけで流れる電流を確かめる。そのあと **GND → 信号の 7 本 → 3.3 V → 5 V** の順に 1 グループずつ戻し、そのたびに電流を見る。上がったグループの線を見直す(隣のピン・隣の列に挿していないか。RESET の 18 番の隣の 17 番は GND、Mega の 5V の隣は VIN)。
4. HM310 を入れたまま USB を挿す(VIN が 6.6 V を超えていると Mega は VIN から電源を取る)。シリアルモニタを開く。

## 6. ファームで 1 段ずつ確かめる

| コマンド | 合格 | 合格しないとき |
|---|---|---|
| `id` | 下位 3 bit が `000` | 下の「`id` が読めないとき」 |
| `mon` | AVDD 4.8〜5.1 V、DVDD 3.2〜3.4 V、温度が室温 + 数 ℃ | AVDD が低い: R1 の向こうで電流が流れすぎていないか(R1 が熱い) |
| `v 0 com` | 1.244〜1.256 V(REFOUT 2.5 V の半分。1% の抵抗 2 本の誤差で ±0.5%) | 0 V 付近: AIN0 の線。2.5 V 付近: 下側の 10 kΩ |
| `refdiff` | ±1.75 mV 以内(内蔵 ±0.05% と ADR4525 ±0.02% の和) | 大きく外れる: AIN4・AIN5 の線、C8・C5 |
| `noise 100` | 標準偏差がデータシートのノイズの表(20 SPS、利得 1)と同じくらい | 何倍も大きい: AVDD を電池に替えて比べる(USB の 5 V のノイズか) |

### `id` が読めないとき(上から順に)

1. RESET(D5)が High、START(D4)が Low か(テスターで)
2. CS(D53)が Mega の SPI の決まりどおり出力になっているか(ファームでは設定済み)
3. DIN と DOUT が逆になっていないか(Mega の D50 = MISO は ADC の DOUT、D51 = MOSI は ADC の DIN)
4. DVDD に 3.3 V、IOVDD に 5 V が来ているか(ADC のピンの根元で測る)
5. CLK(17)が GND か(浮いていると内蔵の発振器にならない)
6. OWON で SCLK と DOUT を見る(SCLK が出ているのに DOUT が動かなければ ADC 側、SCLK も出なければ Mega 側)

## 7. 記録する(log.md に)

```
## 2026-11-xx
- A の段を組んだ。変換基板の番号: DIP = QFP(か、違えばどう違ったか)。はんだ付けで困ったこと: …
- 通電: Mega だけ xx mA → ADC を挿して xx mA(9 V、HM310)
- id: OK / mon: AVDD x.xxx V、DVDD x.xxx V、温度 xx ℃
- v 0 com: x.xxxxx V(期待 1.25 V)
- refdiff: x.xxx mV(ADR4525 をはんだ付けした日から x 日目)
- noise 100: 平均 x µV、標準偏差 x µV
```

段の区切りで、予測と実測のずれは README の「予測と実測」の表へ、ソフトに戻すことは `[ソフト]` を付けて書く。
