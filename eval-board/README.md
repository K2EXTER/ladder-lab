# 評価基板: シミュレーションと実測を比べる

LDO 電源・RC フィルタ・ダイオードの3ブロックを1枚にした、60×36 mm の小さな基板です。
**目的は、circuitCad の解析の結果が実物とどれだけ合うかを確かめること**です。
合わなかったときは、モデルのどこが違うかを探す手がかりになります。

- 回路図: `eval_board.schjson`(試験用の電源 V1・V2 は「シミュレーション専用」で、基板には出ません)
- 基板: `eval_board.pcbjson`(絵は `board_top.png`)
- この文書の「予想値」は、circuitCad のシミュレーションの答えです(2026-11-07 時点)。部品の値は公称値で、実物の許容差は入っていません。

## 1. 基板の構成

| ブロック | 回路 | 測定用の端子 |
|---|---|---|
| 電源 | J1(5 V 入力)→ AMS1117-3.3(U1)。入力 C1 22 µ(セラミック)、**出力 C2 22 µ(タンタル)**、負荷 RL 150 Ω | J3 の 3.3V と GND |
| RC フィルタ | J2(信号入力)→ R1 1 k・C3 100 n → R2 1 k・C4 100 n | J3 の F1(1段目)と F2(2段目) |
| ダイオード | 3.3 V から R3 220 Ω / R4 1 k / R5 10 k を通した 1N4148 ×3 | J4 の A1・A2・A3(アノード側の電圧) |

J3 は左から F1・F2・V33・GND、J4 は左から A1・A2・A3・GND、J1 は左から GND・5V(VIN)(右の四角いパッドが 1 番の 5V。**電源を逆につながないこと**)、J2 は左から IN(SIG)・GND です。**この端子名は、基板のシルク(白い印刷)にも、パッドの上側(J1 だけは下側)に印刷してあります**(文字の高さ 0.8 mm。J3 の「V33」と「GND」は少し詰まっています)。

### 型番を選んだときの注意

- **C1 を 10 µF から 22 µF に変えた**: 10 µF の 0805(Samsung `CL21A106KAYNNNE`・`CL21A106KOQNNNE`、Murata `GRM21BR61E106KA73L`)は、確かめた時点で DigiKey の在庫が 0 でした。22 µF の Samsung `CL21A226MAQNNNE` と Murata `GRM21BR61E226ME44L` も、前者は生産中止、後者は在庫 0 でした。AMS1117 の入力側は大きめでも問題ないので、C1 と C2 を同じ 22 µF にして、部品の種類を減らしました(回路図と基板も更新済み)。
- **C2 を、セラミックから実在のタンタルに替えた理由**: UMW のデータシートは、出力コンデンサに「22 µF **タンタル**で全条件をカバー」としか書いていません(セラミックでよいとは書いてありません)。AMS1117 や LM1117 の系列は、ESR(コンデンサの内部抵抗)が極端に低いセラミックだけだと発振することがある、とされています(**これは私の記憶で、このデータシートでは確かめていません**)。タンタルの ESR 2.2 Ω(最大)が、その安定化に使われる値です。
  - **タンタルは極性があります**。1 番ピン(左のパッド、基板のシルクに「+」と縦線が印刷してある側)が +(部品本体の帯の側)で、V33 につなぎます。逆につなぐと壊れます(逆電圧は定格の 15 % まで、短時間だけ)。
  - 入力側 C1 は、セラミックのままです。AMS1117 の入力側は、データシートの図で特に条件がありません(確認はしていません)。
- **セラミックコンデンサ(C1)の容量は、電圧で大きく減ります(DC バイアス)**: Samsung の特性表(CL21A226MOQNNN、画像)のグラフを画素から読むと、22 µF は 3.3 V で約 −43 %(約 12.5 µF)、5 V で約 −61 %(約 8.5 µF)でした(1 V −4 %、2 V −22 %、3 V −39 %、4 V −52 %、8 V −77 %、16 V −91 %。**グラフの読み取り誤差は数 %**)。この基板の C1(5 V)には、回路図の値に `BIAS=61` を書いて、この減った容量でシミュレーションしています(`22u BIAS=61` なら 8.58 µF)。購入リストと部品表の値は、`BIAS=` が落ちて `22u` のままです。
  - これは**電圧に応じて動くモデルではなく、使う電圧での一定の値**です。±20 % の許容差は別に効きます。
  - **この基板の予想値(V33・フィルタ・ダイオード)は、C1・C2 の容量では変わりません**。変わるのは、電源の出力インピーダンスです(`zout V33` で、100 Hz が約 49 Ω、1 kHz が約 5.4 Ω、10 kHz が約 1.3 Ω)。負荷が急に変わったときの V33 の揺れ(リップルの測定)と、**発振するかどうか**は、AMS1117 のモデルが入出力コンデンサの影響を持たないので、**予想値は出せません**。実測の値だけが頼りです。
  - C3・C4(100 nF の X7R)は、使う電圧が 1 V 以下なので影響は小さいはずですが、特性表は読んでいません。
- **U1 は純正の AMS1117 ではなく UMW 製**です。UMW のデータシート(2025-03 版)の AMS1117-3.3 は、出力電圧 3.234 / 3.300 / 3.366 V(最小 / 標準 / 最大。10 mA・入力 5 V・25 ℃ のとき。精度 2 %)、ドロップアウト 最大 1.30 V @ 1 A、**静止電流 標準 5 mA・最大 10 mA**、負荷変動 最大 18 mV(10 mA〜1 A)です。同梱の `AMS1117-3.3` モデルは静止電流を持たないので、**実測の入力電流は予想より 5 mA 前後(最大 10 mA)多く**なるはずです(DigiKey の一覧には静止電流 2 mA とありますが、データシートの値を使います)。
- 秋月電子では、この基板の 0805(秋月の表記は「2012」)の 220 Ω・150 Ω の抵抗と 100 nF のコンデンサが見つからず、AMS1117 も扱いがありませんでした(検索した範囲)。そのため DigiKey にしています。

基板の穴は M3(穴径 3.2 mm)が 4 個です。足(スペーサ)を付けると、机の上で測りやすくなります。

> フットプリントの寸法は、データシートの図面と照合済みです(「9. フットプリントとデータシートの照合」を参照)。

## 3. 組み立て

1. 基板を目で見て、配線のショートや欠けがないか確かめる。
2. 小さい部品から: 抵抗 → コンデンサ(0805)→ U1(SOT-223)。U1 は大きいタブ(出力)も、はんだを流す。
3. ダイオード D1〜D3 を付ける。**向きに注意**: シルクの四角い枠の**右寄りに、太い縦線(カソードの帯)が印刷してあります**(右の四角いパッドの手前)。ダイオードの黒い帯がある足を、この線に近い側(四角いパッド側。電気的には GND 側のカソード)に向ける。アノード側の丸いパッドは、抵抗(R3〜R5)につながっています。
4. ピンヘッダを付ける(J1 は U1 の左下、J2 は左上、J3 と J4 は上側)。
4b. **C2(タンタル)の向き**: 本体の帯(+ の印)がある側を、シルクの「+」と縦線がある側(左のパッド)に向ける。逆向きは壊れます。
5. はんだ付けのあと、フラックスを洗う(低い電圧や高い抵抗を測るので、汚れが漏れ電流になる)。

### 通電前の点検(テスターの導通/抵抗)

- J1 の 1 番(VIN)と 2 番(GND)の間が**ショートしていない**こと(数百 Ω 以上、または開放)。
- J3 の V33 と GND の間も、ショートしていないこと(RL などがつながるので、数十〜百数十 Ω が目安)。
- J2 の SIG と GND の間が、ショートしていないこと。
- U1 の**タブ(大きい金属の面)と、2 番ピン(中央の足)の間が導通している**こと(テスターで 0 Ω 近く)。基板はタブを出力(V33)につないでいます。データシートの文章でタブの接続先を確かめられたのは TO-252 の図だけで(UMW の資料と Advanced Monolithic Systems の原本)、SOT-223 の図ではタブに印がありません。実物で確かめておくと、はんだ付けの前に分かります。

## 4. 測定の前に、部品を測っておく

予想値との比べ方が変わるので、**電源を入れる前に実測を残す**:

| 測るもの | 道具 | 記録 |
|---|---|---|
| R1・R2・R3・R4・R5・RL の抵抗値 | テスター | 実測値 |
| C3・C4 の容量(基板に付ける前) | LCR メーター(なければ省略) | 実測値 |

測ったら、回路図の値を実測値に置き換えて(`value R3 218` など)から比べると、「部品の許容差」と「モデルの違い」を切り分けられます。

## 5. 測定 A: LDO 電源

道具: 安定化電源(または USB の 5 V)・テスター。可能ならオシロスコープ。

1. J1 に 5.0 V をつなぐ(1 番 = 右の四角いパッド「5V」が +、2 番 = 左の丸いパッド「GND」)。入力電圧を**テスターで実測**して記録する。
2. J3 の V33 と GND の電圧を測る。
3. J1 に入る電流(電源の表示、またはテスターの電流レンジ)を記録する。
4. J3 の V33 と GND の間に 100 Ω を足して(J3 の端子に抵抗の足を当てる)、V33 と J1 の電流を、もう一度測る。

| 測るもの | 予想値(シミュレーション) | 実測 |
|---|---|---|
| V33(RL 150 Ω と、ダイオード3本が付いた状態) | 3.299 V | |
| 入力電流 | 約 37 mA(実物は静止電流の分、標準 5 mA・最大 10 mA ほど多くなる見込み) | |
| 100 Ω を足したときの V33 | 3.297 V | |
| 100 Ω を足したときの入力電流 | 約 70 mA(同上) | |

見るところ:

- 使う UMW 製 AMS1117-3.3 の出力電圧は、データシートでは **3.234〜3.366 V**(10 mA・入力 5 V・25 ℃ の条件)です。**この範囲に入れば合格**と見ます(スペック表にも入れてあります)。シミュレーションの 3.299 V は標準値 3.300 V に近い値です。
- 負荷を足したときの V33 の変化(予想 約 2 mV)は、モデルの「出力抵抗」の確認になります。テスターの分解能が足りないときは、4 桁以上の表示のものを使います。
- リップル(オシロスコープの AC 結合で V33 を見る)は、このシミュレーションが電源を理想として扱うので**予想値がありません**。実測の数字だけ残しておきます。

## 6. 測定 B: RC フィルタ

道具: ファンクションジェネレータとオシロスコープ。

接続: ジェネレータを J2(1 番が SIG、2 番が GND)に。オシロスコープのプローブを J3 の F1 と F2 に当てる。入力の振幅は 1 Vpp 程度、DC オフセットは 0。
プローブは 10:1 にすると、プローブの容量(1:1 だと 100 pF 以上)が測定に影響しにくくなります。

### 周波数応答(正弦波)

各周波数で、入力と出力の振幅比を dB にします(20×log10(出力 / 入力))。

| 周波数 | F1 の予想 | F2 の予想 | F1 の実測 | F2 の実測 |
|---|---|---|---|---|
| 100 Hz | −0.10 dB | −0.12 dB | | |
| 1 kHz | −4.49 dB | −5.93 dB | | |
| 10 kHz | −16.6 dB | −32.6 dB | | |
| −3 dB の周波数 | 約 699 Hz | 約 596 Hz | | |

(−3 dB は、出力の振幅が入力の約 0.71 倍になる周波数です。)

(ハンディオシロで測るときは、「測定器について」の節を先に読んでください。)

10 kHz 付近は、オシロスコープの分解能では、F2 の出力が小さすぎる(入力 1 Vpp に対して約 24 mVpp)ことがあります。入力を大きく(2〜3 Vpp)するか、平均化を使います。

### 立ち上がり(矩形波)

ジェネレータを 100 Hz の矩形波(0〜1 V)にする。

| 測るもの | F1 の予想 | F2 の予想 | F1 の実測 | F2 の実測 |
|---|---|---|---|---|
| 立ち上がり(10 %→90 %) | 約 0.51 ms | 約 0.59 ms | | |

見るところ: 1段目の出力(F1)は、2段目をつなぐ負荷の影響を受けます。**F1 を測るとき、F2 側が付いたままでも、予想は上の値です。**

## 7. 測定 C: ダイオード

道具: テスター(電圧レンジ)。

1. J1 に 5.0 V をつなぎ、V33 を測る(測定 A と同じ)。
2. J4 の A1・A2・A3 を、GND に対して測る。これがダイオードの順電圧 Vf です。
3. 電流は、抵抗の両端の電圧から出す: I = (V33 − Vf) ÷ 抵抗の**実測値**。

| ダイオード | 抵抗 | 予想の電流 | 予想の Vf | 実測の Vf | 実測から出した電流 |
|---|---|---|---|---|---|
| D1 | 220 Ω | 11.8 mA | 0.703 V | | |
| D2 | 1 kΩ | 2.67 mA | 0.630 V | | |
| D3 | 10 kΩ | 0.277 mA | 0.526 V | | |

見るところ:

- 3点の Vf を、電流を横軸に取って(対数の目盛りで)並べると、ほぼ直線になります。その傾きが理想係数 N、切片が飽和電流 IS に対応します。
- ここが**一番モデルと実物の差が出やすい**所です。同梱の 1N4148 のパラメータは「一般的な公開値」で、メーカーや製造ロットで違います。
- 差が出たら、`part-lib` の `diode.rs` のように、グラフの点から IS・N・RS を決め直す方法が使えます(実測の 3 点で試せます)。
- 同じ電流でも、温度で Vf は変わります(目安として 1 ℃ あたり約 −2 mV)。部屋の温度も記録しておくとよいです。

## 測定器について: OWON のハンディオシロ(HDS200 シリーズ)で測るとき

OWON HDS200 シリーズ(HDS242・272・2102・2202、「S」付きはマルチメータと信号発生器つき)のデータシートを読んで、この基板の測定に使えるかを調べた結果です。**ほかのシリーズ(HDS-N など)は、仕様が違います**。持っている機種のデータシートで、下の値を確かめてください。

| 帯域 | 40 / 70 / 100 / 200 MHz(機種による) |

| 測定 | 判定 | コツ |
|---|---|---|
| V33・ダイオードの電圧 | ◎ | マルチメータで足ります。V33(3.3 V)は 20 V レンジで約 ±15 mV で、規格の幅(3.234〜3.366 V)に対して十分です。ダイオード(0.5〜0.7 V)は 2 V レンジが使えます。 |
| フィルタの周波数応答(100 Hz〜1 kHz 付近) | ○ | 発生器は 1〜2 Vpp にします。**J2 の入力電圧を、その周波数ごとに、オシロで測ります**(発生器の表示を信じない)。 |
| −3 dB の周波数 | ○ | **同じチャンネル・同じ V/div で、入力(J2)と出力(F1・F2)を、プローブをつなぎ替えて測り比べます**。ゲイン精度 3 % の誤差が打ち消されます。出力 / 入力が 0.707 になる周波数を探します。 |
| 10 kHz の F2(−32.6 dB) | △ | 入力 2 Vpp でも出力は約 47 mVpp で、10 mV/div(8 ビット)では粗く、平均化もできません。**飛ばして、F1 の 10 kHz(−16.6 dB)を使うほうが確実**です。 |
| 立ち上がり(約 0.5〜0.6 ms) | ○ | 100 Hz の矩形波(DC オフセットで 0〜1 V)を入れ、**100 µs/div** で、10 %→90 % をカーソルで読みます。自動の立ち上がり時間の測定は HDS2102・2202 だけです。 |
| V33 のリップル・発振 | △ | 最小感度 10 mV/div なので、**数 mVpp 以下の揺れは分解できません**。AC 結合・1X プローブ・帯域制限なしで見ます。大きな発振(数十 mV 以上)の有無を見る用途です。予想値との比べ合いは、できません。 |

### 注意すること

1. **発生器の出力インピーダンス 50 Ω は、J2 の入力電圧を測れば、関係しません**(50 Ω は J2 より手前にあります)。ただし、**発生器の設定した振幅を、そのまま入力として使うと**、R1 に 50 Ω が足された形になります。その場合のシミュレーションは、R1 を 1050 Ω にして計算してください(−3 dB は F1 が約 667 Hz、F2 が約 575 Hz。1 kHz で F1 −4.72 dB、F2 −6.17 dB、10 kHz で F1 −16.97 dB、F2 −33.04 dB)。J2 を測る方法なら、この補正は要りません(予想値は、表のままです)。
2. **リップルを見るときは、1X プローブを使います**。10X プローブだと画面の最小感度が 10 倍(100 mV/div 相当)になり、mV 単位の揺れが見えません。1X プローブは、帯域が数 MHz に落ちるのが一般的です(私の知識で、あなたのプローブの値は確認していません)。
3. **GND クリップは、基板の GND(J3・J4 の GND ピン)に 1 本だけ**つなぎます。発生器の GND とオシロの GND が内部でつながっているかは、データシートでは確かめられませんでした。つながっているものとして、接続を 1 点にそろえてください。
4. 取り込みは、サンプリングだけです。**揺れが大きいときは、画面を止めて(ホールド)、カーソルで読みます**。

## 部品の許容差による予想の幅(モンテカルロ、2026-11-09)

抵抗 ±1 %・コンデンサ ±10 %(部品表の値)の範囲で、値を一様にばらつかせて解いた結果です(DC と AC は 2000 回、過渡は 400 回。`sim-core` の `monte_carlo`、seed 1)。**95 % の範囲**は、結果を小さい順に並べた 2.5 %〜97.5 % の値です。数枚組んだ基板の実測がこの範囲に散らばっていれば、ずれは部品の個体差で説明できます。外れるなら、モデルか測り方を疑います。

| 測るもの | 公称 | 95 % の範囲 | 最小〜最大 | 一番効く部品 |
|---|---|---|---|---|
| F1 の −3 dB | 699 Hz | 647〜758 Hz | 636〜780 Hz | C4・C3・R1 |
| F2 の −3 dB | 596 Hz | 551〜648 Hz | 543〜665 Hz | C4・C3・R1 |
| F1 の立ち上がり | 0.507 ms | 0.469〜0.549 ms | 0.461〜0.557 ms | C4・C3 |
| F2 の立ち上がり | 0.586 ms | 0.541〜0.635 ms | 0.532〜0.642 ms | C4・C3 |
| V33 | 3.2989 V | ±0.01 mV ほど | — | RL |
| A1 / A2 / A3 | 0.703 / 0.630 / 0.526 V | どれも ±0.5 mV ほど | — | R3 / R4 / R5 |

**フィルタの幅は、ほぼ C3・C4 の ±10 % で決まります**(抵抗の ±1 % は小さい)。組む前に C3・C4 を LCR メーターで測って回路図に入れれば、予想はずっと狭くなります(4 章)。

**V33 とダイオードの幅は、ほとんど 0 に見えますが、実物の幅ではありません。** このばらつき解析が動かすのは抵抗・コンデンサ・コイルだけで、AMS1117 の出力電圧(規格 3.234〜3.366 V)と 1N4148 の Vf の個体差は動かしていません。実物の幅は、ほぼこの2つで決まります。ダイオードの Vf は温度でも約 −2 mV/°C 変わります。V33 とダイオードは、幅と比べるのではなく、公称値からのずれをそのまま「モデルの誤差+個体差」として記録します。

## 8. circuitCad で比べる

1. 実測した抵抗値と入力電圧を、回路図に入れる(`value R3 218` など)。
2. 解析を回す: DC(動作点)、AC(周波数応答)、過渡(立ち上がり)。
3. スペック表の「実測」列に実測値を入れ、`sim-core` の `compare_measured` で差を見る(画面の「実測」の列)。
   - 何枚か組んだときは、`3.29, 3.31, 3.30` のようにカンマで区切って並べる(A・B・C の順に ✓△× と、平均・最小〜最大が出る)。
   - 先に「解析」タブの「温度とばらつき」で、許容差は**抵抗 1・コンデンサ 10**(%)。`eval_board.schjson` に保存してあるので、開けばこの値になる(既定は抵抗 5 %。変えたら保存する)。DC電圧と -3dB点の行には、この許容差での最悪ケースの範囲と、実測がその内側か外側かが出る。V33 とダイオードは、抵抗・コンデンサの許容差ではほとんど動かないので「ほとんど動きません」と出る(IC とダイオードの個体差は、モデルに入っていない)。
   - 周波数応答は、AC 解析の波形の左の「実測を重ねる」に `1k -4.5` のように「周波数 dB」を貼ると、ボード線図に点で重なり、点ごとの差と、実測の -3dB点が出る。「周波数・入力・出力」を選べば、オシロで読んだ振幅をそのまま貼れる(dB は自動で計算)。
   - 立ち上がりは、オシロの CSV を過渡解析の波形の「実測を重ねる」の「CSV を読む…」で読む(値の列は CH1 なら 2)。「立ち上がりを合わせる」で時刻をそろえると、10→90 % の時間が実測とシミュレーションで並ぶ。
   - 重ねた実測は、回路図と一緒に保存される。
4. 差が大きい所を、次のように探す:

| 症状 | 疑うこと |
|---|---|
| フィルタの −3 dB が、予想よりずっと低い/高い | C3・C4 の実際の容量(許容差・DC バイアス)、プローブの容量 |
| 10 kHz の減衰量が合わない | オシロスコープのノイズ、ジェネレータの出力インピーダンス(50 Ω)、配線の浮遊容量 |
| V33 が許容差の外 | 入力電圧の測り方、テスターの確度、U1 の個体差 |
| Vf が全部同じ向きにずれている | 1N4148 のモデルのパラメータ(IS)、温度 |
| Vf が電流によってずれ方が違う | 直列抵抗 RS、または理想係数 N |

回路図 `eval_board.schjson` のスペック表(解析タブ)に、次の 6 行を入れてあります。測ったら、「実測」欄に値を入れると、範囲に入っているか・差がどれだけかが出ます。まず DC 解析と AC 解析(信号源 V2 の AC 1)を実行してください。

### 0805 の違いについて

YAGEO の推奨ランドは、リフロー(機械で一括して溶かす)で部品が立つ「ツームストン」やはんだのブリッジを避けるための値です。この基板のパッドは、一般的な CAD のライブラリに多い寸法で、**手はんだなら実用上の問題は小さい**はずです(パッドが部品の下に 0.25 mm ほど入り込み、はんだごてが当てやすくなります)。ただし、ここで「問題ない」と言えるのは寸法の比較だけで、実際にはんだ付けして確かめたものではありません。**(2026-11-09 の注: 下のリフロー版は、手はんだ版を手でととのえる前(11-07 の昼)の配置のままで、今の手はんだ版とは U1・C1・C2・J1 の位置が違います。使うときは、今の手はんだ版から作り直してください。)** リフローや部品実装を頼むときは、YAGEO の推奨値に合わせた版 **`eval_board_reflow.schjson` / `eval_board_reflow.pcbjson`**(絵は `board_top_reflow.png`)を使います。0805 の抵抗・コンデンサのフットプリントが `R_0805_Reflow` / `C_0805_Reflow`(全長 3.0・すき間 1.2・パッドの長さ 0.9・幅 1.2 mm)で、そのほかは(手でととのえたあとの)手はんだ版と同じ配置・同じ配線で、パッドだけを置き換えてあります。DRC は 0 件、JLCPCB の発注前チェックはエラー・警告とも 0 件でした。Samsung のコンデンサには推奨ランドの図が無いので、コンデンサも同じ数値にしてあります(根拠は YAGEO の抵抗用)。
