# 評価基板の実測の記録(ひな形)

このファイルをコピーして `measured_YYYY-MM-DD.md` にし、空欄を埋めます。手順と注意は [README.md](README.md) の 3〜7 章。
組んだ基板ごとに A・B・C と名前を付け、**基板の裏にも油性ペンで書いておく**(あとで測り直したときに取り違えないため)。

- 「予想」は公称値のシミュレーション、「95 % の範囲」は部品の許容差(抵抗 ±1 %・コンデンサ ±10 %)のモンテカルロ(`ccad` の `mc`、2026-11-09)。
- V33 とダイオードの Vf は、モデルで個体差を動かせないので範囲がありません(README の「部品の許容差による予想の幅」)。V33 は規格の範囲で見ます。
