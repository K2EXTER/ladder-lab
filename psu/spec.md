# 線形電源 v1 仕様(案)

段階 1 の 2 台目。DMM の次に作り、このあとの電子負荷・カーブトレーサの相手になる。共通の土台(`../platform.md`)の上に作る最初の機器。
決めること 1〜5 は 2026-11-15 に案のとおり決めた。数字は目標で、部品を選ぶときにデータシートで確かめ直す。

## 目的と目標

- 測りたい回路に、**静かで正確な**直流を出す(スイッチング電源のノイズを嫌う、アナログ・測定の回路のため)。
- DMM で校正し、DMM の直線性を確かめる相手になる(0〜20 V を細かい刻みで出す)。
- 電子負荷と組んで、お互いの性能を測る(負荷変動・過渡応答)。電子負荷と組んでカーブトレーサにする。

## 出力

| 項目 | 目標 | メモ |
|---|---|---|
| 電圧 | 0〜20 V | 入力 24 V で決定(`../platform.md`)。12 V の入力では上限が約 9 V に下がる |
| 電流 | 0〜2 A | 24 V・3 A(72 W)のアダプタで 20 V・2 A(40 W)に余裕がある |
| 小電流のレンジ | 0〜20 mA、分解能 1 µA | ダイオードや LED の小さな電流、カーブトレーサの立ち上がりの部分 |
| 設定の分解能 | 1 mV・0.1 mA(小電流のレンジは 1 µA) | 16 ビットの DAC で 20 V / 65536 ≈ 0.3 mV |
| 設定の確かさ(校正後) | ±(0.05 % + 2 mV)、±(0.1 % + 1 mA) | DMM(0.01〜0.02 %)で校正する。DMM より 1 桁甘くしておく |
| 読み返しの確かさ(校正後) | ±(0.02 % + 1 mV)、±(0.05 % + 0.5 mA) | 出力の電圧と電流を自分の ADC で読む |
| ノイズ | 1 mV rms 以下、5 mVp-p 以下(20 MHz の帯域) | 線形にする理由。手元のオシロ(HDS2202S)で測る |
| 負荷変動 | 0.01 % + 1 mV 以下(0→全負荷) | リモートセンスで測る端子の電圧を保つ |
| 入力の変動 | 0.01 % + 1 mV 以下(入力 22〜26 V) | |
| 過渡応答 | 負荷を 10 %↔90 % に変えて、10 mV 以内に 100 µs で戻る | 電子負荷ができたら測る |
| 出力の数 | 1 | ± や 40 V は 2 台を直列にする(1 台ずつ浮いているのでできる) |

## 動き

- **定電圧(CV)と定電流(CC)**を自動で切り替える。CC に入ったら表示と PC に知らせる。
- **リモートセンス**(+S・−S の端子で、負荷の端の電圧を保つ)。センスの線が外れても出力が上がりすぎない保護を付ける。
- 出力のオン・オフはリレーで切る。オン・オフの瞬間に跳ねない(オンは 0 V から上げる)。
- 保護: 過電圧(設定 + 余裕で切る)、過熱(放熱器の温度で切る)、逆電圧(外から電圧をかけられたとき)、出力の短絡(CC で受ける)。
- 前面の操作: v1 は PC の画面と OLED の表示だけ。つまみ(ロータリーエンコーダ)はあとで。

## 構成

```
24 V 入力 → 前段の降圧 DC-DC(出力 + 約 3 V に追従)→ 線形の段(パス素子 + CV と CC の帰還)→ 出力のリレー → +・−・+S・−S
                                                   ↑ DAC で電圧と電流の目標      ↓ ADC で電圧と電流を読む
                                               コア基板(Pico 2、共通コネクタ、`../platform.md`)
```

| 部分 | 案 | 理由 |
|---|---|---|
| 前段 | 同期整流の降圧 DC-DC。出力の電圧に合わせて入力を下げる(パス素子の両端を約 3 V に保つ) | パス素子の熱を、最悪でも約 3 V × 2 A = 6 W にする。追従しないと 24 V × 2 A ≈ 48 W になる |
| パス素子 | N チャネル MOSFET か NPN のダーリントン。放熱器とファン | 放熱器の大きさは circuitCad の自己発熱と、候補 H6(ヒートシンクの計算)で決める |
| CV と CC の帰還 | オペアンプのアナログの帰還(マイコンは目標の値を出すだけ) | 速さと安定のため。マイコンの帰還では過渡応答が遅い |
| 電流の検出 | シャント抵抗 + 差動増幅。2 A と 20 mA の 2 本(レンジはリレーかスイッチで) | 小電流のレンジは別のシャント |
| DAC | 16 ビット、2 ch(電圧と電流の目標) | |
| ADC | 16〜24 ビット(電圧と電流) | DMM の ADS124S08 と同じ系統にすると、ファームと校正の作りを使い回せる |
| 基準 | 電圧基準 IC(DMM と同じ ADR4525 を使い回す案) | 部品と知見の使い回し |
| 名札 | 共通の土台の EEPROM に校正の値 | `../platform.md` |

## circuitCad で先に確かめること

基板を作る前に、シミュレーションで次を見る。違いが出たら、Ladder Lab のフィードバック(README)に戻す。

- **ループゲイン**(CV と CC の帰還の安定。容量性の負荷 0〜1000 µF で位相余裕 45° 以上)
- **過渡解析**(負荷の急変、CV と CC の切り替わり、オン・オフの跳ね)
- **PSRR**(前段の降圧のリップルが出力にどれだけ届くか)
- **ノイズ解析**(出力のノイズの見積もり、どの部品が効くか)
- **自己発熱**(パス素子の温度。半導体も温めるようになった H1 で)
- 前段の降圧は、平均化したモデルが無いので(候補 J22)、まずリップルの電圧源で近似する

## 試作の段階

| 段 | 基板 | 中身 | 確かめること |
|---|---|---|---|
| A | ブレッドボード + 放熱器 | 線形の段だけ(前段なし、入力は HM310 から)、DAC と ADC はモジュール | CV と CC の帰還が安定か、ノイズ、circuitCad の予測と合うか |
| B | ユニバーサル基板 | 前段の降圧の追従を足す、リモートセンス、保護、共通コネクタ | 熱、追従、保護 |
| C | プリント基板 | 全部。共通の土台の箱と前面の板 | 目標どおり |

## 確かめ方

| 項目 | 何で |
|---|---|
| 電圧の設定と読み返し | DMM(0〜20 V を 1 V ごと)。DMM の直線性もいっしょに見る |
| 電流 | 基準のシャント抵抗 + DMM |
| ノイズ | オシロ(HDS2202S、20 MHz の帯域制限) |
| 負荷変動・過渡応答 | 電子負荷(できるまでは抵抗の切り替え) |
| 熱 | 温度ロガー |

## 決めたこと(2026-11-15)

1. 電流の上限は 2 A
2. 小電流のレンジ(0〜20 mA、1 µA)を入れる(カーブトレーサで要る)
3. リモートセンス(4 端子)を入れる
4. 出力は 1 つ(± は 2 台を直列に)
5. 前面のつまみは v1 では入れない(PC と OLED から始める)
