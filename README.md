# Ladder Lab — 自作の測定器を育てるプロジェクト

測定器・電源・電子負荷を簡単なものから作り、作った機器同士でお互いの性能と精度を上げていく連載の、回路図・ファーム・PC のスクリプト・手順書・作業の記録です。

- 記事: [Ladder Lab (1) 測定器を自作する: 3000 円の ADC を壊さずに動かすまで](https://zenn.dev/k2exter/articles/5ff24daec3b92a)(Zenn)
- 回路図は自作の回路 CAD [circuitCad](https://github.com/K2EXTER/circuitCad) で描いています(`.ccad` はスクリプト、`.schjson` は回路図。circuitCad で開けます)
- 回路図・ファーム・スクリプト・手順書は、AI(Claude Code)が書き、作者が組み立てて確かめています。組み立てて確かめたのは試作 A まで(`log.md`)。B の段の回路図は設計の途中です
- 回路図を見るだけなら `.schjson` を circuitCad で開いてください(作者がライブラリに足した部品 ADS124S08_TQFP などのデータも、ファイルの中に入っています)。`.ccad` から作り直すには、それらの部品が circuitCad のライブラリに要ります
- ライセンス: MIT(`LICENSE`)

---

プロジェクト名は **Ladder Lab**(2026-11-15 に決めた)。簡単な機器から段(はしご)を一段ずつ上がり、上がった機器で次の機器を確かめていく、の意味。

測定器・電源・電子負荷を簡単なものから作り、お互いの機器で性能と精度を上げていく。
2026-11-10 開始。

## 原則

- 機器同士で上げられるのは **直線性・分解能・ノイズ・安定性・比率**。
- **絶対値**は単位ごとに1つ、外から持ち込む(下の「基準」)。それ以外は比率の測定で広げる。
- 同じ誤差が循環しないように、**校正の記録**(どれを・いつ・何で・どれだけの不確かさで)を必ず残す。

## 基準(外から持ち込むもの)

| 単位 | 基準 | 最初の値の決め方 | 状態 |
|---|---|---|---|
| 電圧 | ADR4525(2.5 V)→ のちに LM399 | 校正済みの DMM で測って記録 | 未 |
| 抵抗 | 0.01% 金属箔抵抗(Vishay)数本 | 購入時の表示値 → 校正済みの DMM で確認 | 未 |
| 周波数・時間 | GPSDO(1PPS に合わせる) | GPS | 未 |

## 手元の機器(2026-11-10)

| 機器 | 仕様(カタログ値) | 役目 |
|---|---|---|
| 共立 KEW MATE 2000A | 3400 カウント、DCV ±1.5% rdg ±4 dgt | 大きな間違いを見つける確認役 |
| OWON HDS2202S | オシロ 200 MHz・1 GSa/s(2 ch、ch 間は非絶縁)、DMM 20000 カウント・DCV ±0.3% + 5 dgt、発生器 正弦波 25 MHz | 波形・ノイズの確認、DMM は確認役、発生器は段階2の信号源 |
| Hanmatek HM310 | 30 V の直流電源 | DMM の 30 V までの試験。逆に DMM で表示を校正する相手 |
| Arduino Mega | 5 V の I/O、3.3 V 出力あり | 試作 A のマイコンの候補 |

どれも 0.01% の基準にはならない。最初の絶対値は**基準 IC のデータシートの保証値**(ADS124S08 内蔵 ±0.05%、ADR4525 など)に置き、複数の独立した基準を突き合わせて確かめる。

## 段階

| 段 | 機器 | 主な相手 |
|---|---|---|
| 1 直流 | **DMM(電圧・抵抗)** → 線形電源 → 電子負荷、温度ロガー(熱電対・NTC 数 ch) | DMM が電源・負荷の読み値を校正、負荷が電源の負荷変動を測る。温度ロガーは電源・負荷の発熱と、circuitCad の自己発熱・熱の計算の確認(候補 H9) |
| 1.5 | DMM に mΩ レンジ(電子負荷を電流源に使う)、電圧の基準器(独立した箱)、差動プローブ(絶縁)、電流プローブ(シャント + 増幅器、またはホール素子)、カーブトレーサ(半導体の I-V 特性。電源と電子負荷の延長) | シャント抵抗の確認。基準器は DMM の中の基準の見張りと、ほかの機器への値の受け渡し。差動プローブは非絶縁のオシロ(HDS2202S)で GND に落ちていない点を安全に測るため、電源・負荷の試験の前に。電流プローブは電源の過渡応答・突入電流。カーブトレーサの曲線を circuitCad の「かんたん作成」(データシートからモデル)に入れて比べる |
| 2 交流・低周波 | 周波数カウンタ + GPSDO(最初に)→ DDS 発生器・低ひずみ発振器・簡単なオシロ、LCR メータ(DDS + 同期検波)、低ノイズの前置増幅器、ロジックアナライザ(RP2040 の PIO か小さな FPGA) | 循環を切るため熱形 RMS か電力検出器を入れる。GPSDO が周波数の絶対値、カウンタが DDS とオシロの時間軸を確かめる。LCR メータで MLCC の DC バイアス・ESR・コイルを測り部品のモデルと比べる。前置増幅器で nV の雑音を測りノイズ解析と比べる。ロジックアナライザはファームの調べと、FPGA の練習台(circuitCad の候補 F 節) |
| 3 高周波 | パルス発生器(アバランシェ)・200 MHz オシロ・VNA | パルスでオシロの帯域を確かめる |

おすすめの順(2026-11-15): 温度ロガーと差動プローブは小さく、段 1 の電源・負荷の試験ですぐ使う → カーブトレーサは circuitCad とのつながりがいちばん強い(電源と電子負荷ができたら)→ 段 2 は周波数カウンタ + GPSDO を DDS 発生器より先に置き、周波数の基準を固める。

## 費用(2026-11-15 の見積もり)

全部を一から作ると、作り直し 1 回を含めて**合計 30〜60 万円**ほど。下は大まかな見積もりで、店の値段で確かめたものではない。部品を選ぶときに確かめ直す。

| 機器 | 目安 | 高くなる理由 |
|---|---|---|
| DMM | 3〜5 万円 | 基準の抵抗と ADC。2026-11 の発注で約 3 万円(`order-2026-11*.md`) |
| 線形電源・電子負荷 | 各 1.5〜3 万円 | 放熱器・パワー素子・ケース |
| 温度ロガー・電流プローブ | 各 0.5〜1 万円 | |
| 差動プローブ(絶縁) | 1〜2 万円 | 絶縁の部品 |
| 電圧の基準器 | 1〜5 万円 | 基準の IC の等級しだい(LTZ1000 級なら上の方) |
| カーブトレーサ | 1〜2 万円 | 電源と電子負荷の部品を使い回せる |
| 周波数カウンタ + GPSDO | 1〜3 万円 | GPSDO は買う方が安いことが多い |
| DDS 発生器・低ひずみ発振器 | 1〜3 万円 | |
| LCR メータ・前置増幅器 | 各 1〜2 万円 | |
| ロジックアナライザ | 0.3〜1 万円 | RP2040 なら安い |
| 200 MHz オシロ | 5〜15 万円 | 速い ADC・FPGA・基板の層数 |
| VNA・パルス発生器 | 2〜5 万円 | |

### 費用を抑えるやり方

1. **共通の土台**: マイコンの基板・USB の絶縁・表示・ケース・PC 側の記録(`tools/dmmlog.py`)を 1 つの形にして全部の機器で使い回す。機器ごとの分は、測る部分だけにする。 設計の案は `platform.md`。
2. **機器どうしで部品を使い回す**: カーブトレーサは電源と電子負荷の組み合わせ、LCR メータは DDS 発生器の上に作る。同じ箱に入れれば、ケースも基板も減る。
3. **買うものと作るものを分ける**(下の表)。
4. **基板はまとめて発注する**: 1 回の発注に数枚の機器の基板をまとめて、送料と手数料を減らす(circuitCad の面付け J15 が入ると楽になる)。
5. **やめてもよい所を決めておく**: 段 3(200 MHz オシロ・VNA)はいちばん高く、市販品は 5〜7 万円。段 2 までやってから、作るかどうかを決める。

### 買うものと作るもの

| 分け方 | 機器 | 理由 |
|---|---|---|
| 作る(学びが大きい) | DMM・線形電源・電子負荷・カーブトレーサ・温度ロガー・差動プローブ・電流プローブ・DDS 発生器・LCR メータ・前置増幅器・ロジックアナライザ・周波数カウンタ | 精度の積み上げと、circuitCad のモデルの確かめに直接つながる |
| 買う(外から持ち込む基準・作っても学びが少ない) | GPSDO・熱形 RMS / 電力の検出器・VNA(NanoVNA の類)・基準の抵抗・電圧の基準 IC | 原則の「絶対値は外から持ち込む」と合う。作ると高くつく |
| 段 2 のあとで決める | 200 MHz オシロ・パルス発生器・VNA を作るか | 費用が大きい。段 2 の経験で判断する |

**現実的な線**: 段 1〜2 を共通の土台と使い回しで作り、GPSDO と VNA は買う。合計 **15〜25 万円**ほど。1〜2 年かけて少しずつなら、月 1 万円前後。

## circuitCad へのフィードバック

Ladder Lab は circuitCad を実際に使う場でもある。困ったこと・合わなかったことを、ソフトの改善に戻す。

1. **作業中に 1 行だけ書く**: `log.md` に `[ソフト]` の印を付けて「何をしたかった → どうなった → どう回避した」を 1 行で。手間を最小にする。
2. **段の区切りでまとめる**: 試作 A・B・C や記事 1 本の区切りで、`[ソフト]` の行を circuitCad の `docs/candidates.md` の「L. Ladder Lab から」に移す。候補の表は公開されているので、注文の金額のような私的なことは書かず、一般的な課題として書き直す。
3. **直したら印を返す**: 直したら候補から消し(いつもどおり)、`log.md` の元の行に「済み(コミット)」と書き足す。

いちばん価値が高いのは**シミュレーションと実測のずれ**。段ごとに「予測と実測」の表を作る(下の「予測と実測」)。ずれは部品のモデルの修正(circuitCad の `docs/models/`)に戻す。
